# Easy Laundry

**Live site:** https://ommangrulkar15.github.io/easy-laundry/

**Laundry, booked in one sentence.**

Easy Laundry is a concept app for doorstep laundry, designed for hostel, PG and flat residents. Tell Bubbles, the in-app helper, what needs cleaning, and it fills in the booking with an itemised price before pickup.

This repository is the concept website: a single static page with a working sentence-to-booking demo, a price estimator, a pickup-proof section and an order tracker.
